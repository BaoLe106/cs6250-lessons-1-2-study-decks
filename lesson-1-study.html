End-to-end principle

Put a function in the endpoints when only they can implement it correctly.

Keep the core general; let applications choose reliability, security, and session behavior.

Why: a video call values low delay; a file transfer values correct, ordered bytes. One core policy fits neither perfectly.

Interconnecting hosts and networks

Layer determines what a device can see—and decide.

Layer 1

Hub / repeater

sees: bits/signals

Repeats input to other ports; no destination awareness.

Layer 2

Bridge / switch

sees: MAC address

Forwards local frames toward a learned destination port.

Layer 3

Router / L3 switch

sees: IP address

Forwards packets between networks using an IP table.

Scopes: switches connect a LAN with frames; routers interconnect networks with packets.

Looping problem + spanning tree

Physical redundancy is good. Layer-2 forwarding cycles are not.

Frames have no hop limit. A loop can circulate/flood indefinitely, congest the LAN, and make MAC tables unstable.

STP result: keep all bridges connected, but block selected forwarding ports so active links form a tree with no cycle.
