# CS6250 Network Notebook

A Vietnamese–English study site for CS6250 Lessons 1–12. It contains 104 topic chapters, interactive diagrams spanning network architecture through CDNs, twelve original 60-question practice sets, and links to all 201 non-quiz Canvas lesson pages plus the currently released slides and transcripts.

The site is plain HTML, CSS, and JavaScript. No libraries or build step are needed. Open `index.html` in a browser, or serve this folder over HTTP for normal browser navigation.

The Canvas quiz pages were excluded. Practice questions and worked examples are independently written; they do not reproduce course quizzes or answer keys. Canvas source links may require course login.

# CS6250 Network Notebook

Trang học CS6250 song ngữ Việt–Anh cho Lesson 1–12. Site gồm 104 chương theo chủ đề, sơ đồ/mô phỏng từ kiến trúc mạng tới CDN, mười hai bộ luyện tập tự biên soạn gồm 60 câu mỗi lesson, và liên kết tới 201 trang Canvas không phải quiz cùng các slide/transcript hiện đã phát hành.

Site dùng HTML, CSS và JavaScript thuần; không cần thư viện hay bước build. Mở `index.html` trong trình duyệt, hoặc chạy qua HTTP để sử dụng điều hướng bình thường.

Các trang quiz Canvas đã được loại khỏi phạm vi. Câu luyện và ví dụ được biên soạn độc lập, không sao chép quiz hay đáp án môn học. Có thể cần đăng nhập Canvas để mở nguồn.
