Forwarding vs routing

Routing computes; forwarding acts.

Represent routers as graph nodes and links as weighted edges. A routing protocol chooses useful paths; each router installs next-hop entries and forwards packets locally.

Scope: intradomain routing is within one administrative domain/AS. Interdomain routing crosses AS policy boundaries.

Link-state routing

Everyone learns the topology; each router runs Dijkstra locally.

Input

Flooded link-state information gives routers a consistent graph and edge costs.

Algorithm

Start at source u; repeatedly add the lowest-cost not-yet-final node to N′ and relax its neighbors.

Output

Shortest-path tree from the router to all destinations, then next-hop/FIB entries.

D(v) ← min( D(v), D(w) + c(w,v) )
Complexity: the simple scan implementation is O(n²). Link state trades broader topology dissemination for independent local calculation.

Distance-vector routing

Neighbors exchange their own distance estimates.

DV is iterative, asynchronous, and distributed. Each node maintains a cost vector to destinations and revises it after neighbors advertise theirs.

Dₓ(y) = minᵥ { c(x,v) + Dᵥ(y) }
What x asks

“For destination y, which neighbor v gives the cheapest first hop plus its remaining distance?”

Convergence

Updates stop when no router can improve its vector; a link-cost/topology change starts the process again.

Contrast with link state: DV sees neighbors’ summaries, not necessarily the full graph.

DV failures

Bad-news cost increases can travel painfully slowly.

Count to infinity: neighbors can form a loop by advertising routes that actually depend on one another. Decreases converge quickly; large increases/failures may not.
Poison reverse: if Z reaches X through Y, Z advertises X to Y with infinity. This breaks a two-node loop, but cannot solve every 3+-node count-to-infinity case.

IGP protocol examples

RIP is distance vector; OSPF is link state.

RIP

Hop-count metric; periodic neighbor advertisements; UDP port 520. Tables store destination subnet, next hop, and hop count. A silent neighbor for 180 seconds is unreachable.

OSPF

Floods Link State Advertisements, maintains a link-state database, then runs SPF/Dijkstra. Supports authentication, equal-cost paths, and hierarchy.

OSPF areas: each area runs link state; area-border routers connect them through a single backbone area, improving scalability.

Hot-potato routing

When external routes tie, exit the AS at the nearest egress.

If multiple border routers offer equally good BGP routes, compare internal IGP cost and send traffic to the closest exit point.

Effect: reduces internal resource use by handing traffic to the next AS sooner. It is an intradomain choice that influences an interdomain journey.

Optional · traffic engineering

Measure, model, control.

Measure

Topology, capacities, link weights, and demand via telemetry/traffic measurement.

Model

Predict path/traffic consequences of candidate IGP weights, including equal-cost load splitting.

Control

Apply selected link weights; LS flooding/SPF causes a short transition period.

Operational caution: changing weights is not routine. Even planned changes cause temporary inconsistent views and convergence work.
