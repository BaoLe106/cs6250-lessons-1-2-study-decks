A practical exception

NAT trades pure end-to-end reachability for IPv4 scale.

Firewalls, proxies, and NATs are middleboxes: they inspect or change traffic instead of merely forwarding it.

NAT’s bargain: many private hosts share one public IPv4 address, but unsolicited inbound connections and protocols carrying addresses become harder.

The Internet’s shape

A narrow waist connects diversity to diversity.

Applications need only the waist—not every underlying technology. Networks need only support the waist—not every application.

Power: independent innovation above and below. Cost: changing the waist requires coordinated ecosystem-wide adoption.

EvoArch model

Dependence creates survival value—and eventually lock-in.

1

Birth

New protocol nodes appear and choose dependencies (“substrates”) below.

2

Value

A protocol gains value when many valuable higher-layer “products” rely on it.

3

Competition

Similar same-layer protocols compete; weaker ones are more likely to die.

4

Cascade

A death can remove dependents with no remaining substrate. Repeat → hourglass.

Why TCP/IP endured

Useful early apps → adoption → more dependents → higher evolutionary value.

Design warning

“Technically better” is insufficient. Enable coexistence and smooth transitions, or the new waist may ossify too.

Layer-2 loops

Redundancy needs a loop-free forwarding topology.

Ethernet frames have no hop limit. In a cycle, flooded frames can circulate indefinitely and multiply into a broadcast storm.

STP: keep physical redundancy, but block selected ports so active links form a connected tree—no cycles.

How STP converges

Agree on a root, then keep each best path.

1

Every switch initially claims: “I am root, distance 0.”

2

Neighbors exchange (sender ID, root ID, distance).

3

Prefer lower root ID → shorter distance → lower sender ID.

4

Block ports not needed by the winning paths; the graph becomes a tree.

Graph invariant

A spanning tree connects all V switches with exactly V − 1 active inter-switch edges and no cycle.

3 switches → 2 active edges
Important distinction: a learning table improves forwarding efficiency; spanning tree makes that forwarding safe in a redundant topology.
