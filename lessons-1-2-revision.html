Encapsulation

Message → segment → IP datagram → frame → bits. Reverse at the destination.

Device visibility

Hub: bits. Switch: MAC/frame. Router: IP packet.

Hop fact: the link frame changes at every router; IP enables the end-to-end route.

Lesson 1 architecture choices

Simple core, smart edges, stable waist.

End-to-end

Reliability/security/session functions belong at endpoints when only they know the application goal.

NAT/middleboxes

Useful exceptions: rewrite, filter, or proxy traffic for practical constraints such as IPv4 scarcity.

Hourglass

Many apps and links depend on a narrow core; dependence enables innovation but causes ossification.

Design lesson: protocol quality is not enough for deployment. Coexistence and migration paths determine whether an alternative can win.

Lesson 2 transport service

TCP adds the mechanisms applications commonly need.

Ports + sockets

multiplex/demultiplex many processes on one IP

Handshake

SYN → SYN/ACK → ACK aligns connection state

Reliable bytes

sequence numbers, ACKs, timers, retransmissions

Rate control

rwnd protects receiver; cwnd protects network

UDP contrast: no connection setup, reliability, or TCP-style congestion control; lower overhead and more application control.

The one inequality to own

In-flight data is bounded by two different constraints.

LastByteSent − LastByteAcked
≤ min(cwnd, rwnd)

rwnd: unused receive-buffer space advertised by receiver.
cwnd: sender’s estimate of safe network in-flight data.

Receiver is slow

rwnd falls → sender slows even if path is empty.

Path is congested

cwnd falls → sender slows even if receiver is ready.

Never conflate them: flow control prevents buffer overflow; congestion control prevents queue growth, loss, and collapse in a shared path.

Before the quiz/exam

Explain—not merely recognize—these contrasts.

IP vs TCP

host best effort vs reliable app byte stream

MAC vs IP

local link destination vs across-network host address

UDP vs TCP

minimal/low overhead vs managed connection and reliability

rwnd vs cwnd

receiver protection vs path protection

switch vs router

MAC frame forwarding vs IP packet forwarding

STP vs learning
